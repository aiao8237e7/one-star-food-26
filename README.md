# One Star, Five Stars for the Food

A [make.fun](https://make.fun) entry for the competition
[One Star, Five Stars for the Food](https://make.fun/competitions/u-po-pu-one-star-five-stars-for-the-food-f9166ee7).

An alien tourist gives planet Earth a one-star review while still admitting
the food was excellent. The program writes one sentence — at most 200
characters — to `/output/entry.txt`:

> One star: Earth's traffic jams last longer than our ice ages, the Wi-Fi drops if a cloud looks at it funny, but the street satay is so good I would invade again just for the peanut sauce.

## Run

```sh
node main.ts
```

This writes the sentence to `/output/entry.txt`.
